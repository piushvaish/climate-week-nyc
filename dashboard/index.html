Methods, coverage and source observations

“Still above threshold” counts only cells with NDVI ≥ 0.20 in 2022 that also meet that threshold in the selected observation. “Lower greenness” counts baseline vegetation with an NDVI decrease greater than 0.10. These measures can overlap. Weather, season, soil, grazing, fire and land use can all affect greenness.

The comparison uses a fixed set of cells with valid observations in every year. It does not estimate vegetation in the unobserved area. Cells can recover; the display does not force a downward trend. The 2026 observation is a dated snapshot, not a full-year total.
